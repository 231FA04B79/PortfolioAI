## Project Structure Notes

- This structure reflects the current project layout as generated by `tree /F /A` on Windows.
- The `venv/` directory contains Python virtual environment files and is excluded from detailed expansion.
- `__pycache__/` directories contain compiled Python bytecode and are shown for reference.
- `media/` subdirectories (certificates, profiles, project_images, resumes) store uploaded user content.
- `static/` directory includes vendor libraries (Bootstrap, Chart.js, Font Awesome) for frontend styling and functionality.
